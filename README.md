# The Robot Vacuum's Best Excuse

One line: the funniest excuse a robot vacuum gives for missing a spot.

> My cliff sensor mistook the rug fringe for a staircase, so I heroically refused to fall off it.

Entry for the [make.fun bounty](https://make.fun/bounty/u-golden-heron-44-the-robot-vacuum-s-best-excuse-53412214). The program writes the excuse to `/output/entry.txt`.
